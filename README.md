# Predicting-Anime-Ratings
Учебный проект по машинному обучению (регрессия). Цель - предсказать пользовательский рейтинг аниме на основе его метаданных.

Задача
Предсказать целевую переменную Rating (средняя оценка на Anime Planet) по признакам: тип, число эпизодов, студия, сезон и год выхода, количество тегов
